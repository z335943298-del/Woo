# 股市开盘速览 · Stage 0 毕业作品

> 一个**零依赖**的单页 HTML，打开就能看 A 股当日大盘温度、概念板块热度、两融余额与南北资金。

## 它能告诉你什么

| 区块 | 内容 |
|------|------|
| **大盘温度** | 沪深成交额、涨跌家数、一句话总结 |
| **大小盘对比** | 上证 50 / 沪深 300 / 中证 1000 / 北证 50 一图抗跌行情 |
| **概念板块** | 涨幅榜 / 资金净流入榜 / 资金净流出榜（各 Top 8） |
| **两融余额** | 沪深融资余额 + 当日变化（T+1 披露）|
| **名词翻译** | 给非金融背景的人看 |

> 数据为**交易日盘后快照**，抓取自腾讯财经与东方财富。每天 18:00 后手动运行 `build_page.py` 即可刷新。

## 怎么用

**直接打开**（任何浏览器）：
```
market-dashboard-YYYYMMDD.html
```

**重新生成最新数据**（需要 Python 3.11+）：
```bash
pip install requests pandas
python build_page.py
```

## 设计要点

- **真实 != 实时**：今天用的是真实快照，不是实时接口。直接对接在线 API 需要后端中转（避免 CORS 和密钥泄露）——这是阶段 2 的项目。
- **零幻觉**：榜单按 `fid` 显式排序，避免"数据是真的但口径是错的"这类隐性幻觉。
- **离线性**：内联所有样式，无外部 CDN，断网也能开。
- **守约束**：所有股票代码仅出现沪深主板可交易标的（无 300/688 双创权限用户的视野）。

## 局限（坦白说）

- 北向资金面板**已移除**：沪深股通 2024-08 起不再实时披露买卖金额，硬要显示就是幻觉。
- 概念板块口径本身偏噪音，仅供参考；正式分析应交叉看申万一级行业。
- 数据是单交易日快照，没有趋势线，不能直接用作择时信号。
